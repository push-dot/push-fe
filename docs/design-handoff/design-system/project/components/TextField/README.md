# TextField

A filled input: `fill` background, `radius-md`, 56px tall, 16px text (never smaller: iOS zooms below 16px).

- Placeholder in `t4`, value in `t1`, leading icon 18px in `t3`.
- Multi-line fields put a `c1` bold label on top and a character counter bottom-right ("83 / 500").
- No visible border; focus shows a 2px `ac` ring.
