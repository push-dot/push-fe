# Composer

The AI chat input, the same on the first screen and in conversations.

- 28px-radius box: the text line on top (17px), a control row below: `+` attach, `@ 언급` (mention a 서류, 공고 or 프로필), then mic and send on the right.
- Send is `fill2`/`t4` when empty, `ac` with a white arrow when there is text.
- While the agent works, the right side is a single black stop button, and a StatusRow floats above the box.
- iOS: glass. Android: `bg2`.
