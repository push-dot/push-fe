# ApprovalPanel

The agent asks before it changes something. Replaces the Composer until answered.

- A question in `h3`/18px bold, then 2–4 numbered choices; the recommended one is pre-selected (`ac-soft`). The last choice is always a way to say something else ("직접 말하기").
- Choices may carry a second line in `c1` `t3` and checkboxes when several can be picked.
- Footer hint: "번호를 누르거나 바로 말해도 돼요". On desktop the footer shows keys (↑↓ · Enter · Esc).
