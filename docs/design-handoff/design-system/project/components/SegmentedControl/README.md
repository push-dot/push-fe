# SegmentedControl

Two or three peer views of one screen (마이: 프로필 · 서류 · 내 활동; 제안함: 받은 · 보낸).

- 44px pill track in `fill`; the selected segment is `bg` with `t1` text and a soft lift; others `t3`.
- Labels are nouns, optionally with a count ("받은 제안 4").
- For more than three choices use a chip row instead.
