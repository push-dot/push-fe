# QuickStartPill

Shortcuts above the AI chat composer, one sideways-scrolling row.

- 52px pill, 30px 3D icon + a short verb phrase (≤ 10 characters).
- Tapping never sends a message: it opens a BottomSheet that collects what the task needs (a job, a proposal, sections to edit), then starts the conversation.
- Order: what people do most first (공고 링크로 맞추기, 나에게 맞는 공고 찾기, 부족한 점 찾기 …), social tasks last.
- Hidden once the person starts typing.
