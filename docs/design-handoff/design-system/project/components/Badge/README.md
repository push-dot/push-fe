# Badge

A 22px status label: a soft fill with its matching text colour.

- `ac` (AI, scores, new): "적합도 6.9", "새 제안", "작업 중".
- `grey` (neutral state): "지원함", "읽지 않음".
- `red` (urgent or failed): D-day under 3 days, "불합격", "근거 없음".
- `green` (done): "합격", "수락함", "연결됨".
- `orange` (waiting on the person): "면접", "확인 필요", "초안".
- One or two words. Never more than two badges on one row.
