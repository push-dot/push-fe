# Chip

Filter and choice chips, 34px pills.

- Idle: `fill` with `t2` text. On: `t1` fill with `bg` text (inverted, not violet).
- A chip that opens a sheet ends with a 14px `down` chevron and shows its value when set ("경력 4–6년").
- Multi-select chips show a leading `check` when on; removable tags end with a 12px `x`.
- Rows of chips scroll sideways with the 20px screen gutter; never wrap on the home or list screens. Inside sheets they wrap.
- On iOS idle chips are glass.
