# JobCard

The job posting card on 홈 (horizontal rows) and 채용공고 (2-column grid).

- Photo first: company image 200×136 (`radius-md`), here a brand-colour gradient with the initial as placeholder. Grid version is 169px wide.
- Bookmark: 30px white round button at the photo's bottom-right; saved = filled `ac-text`.
- Below: company (`c1` `t3`), title (`b1` bold, ONE line, ellipsis), location · years (`c2` `t3`).
- No box, no D-day, no fit score on the card: fit score appears only on the job detail.
- Rows show one and a bit cards so the next one peeks.
