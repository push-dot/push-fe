# Switch

On/off for a setting that applies immediately (no save button).

- 51×31, `ac` when on, `fill2` when off; white knob.
- Sits at the end of a settings row inside a grouped list (`bg2`, `radius-lg`). A second line in `c1` `t3` explains what turns on.
- Never for actions that need confirmation (use a button) or for choosing between more than two values (use a select row).
