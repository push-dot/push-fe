# SettingsGroup

iOS-style grouped list for settings, account and filters.

- Section title in 13px bold `t3` above; group in `bg2` with `radius-lg`; rows 56px with `line` hairlines between.
- Row ends with a value + chevron (navigates), a switch (toggles), or a select pill (picks in place, e.g. 언어).
- An optional note under the group in 12px `t3` explains consequences.
- Where a row's label would just repeat its value, show the value alone ("백엔드 엔지니어 ›").
