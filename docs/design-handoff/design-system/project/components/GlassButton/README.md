# GlassButton

iOS 26 Liquid Glass buttons for top bars: a round 44px icon button, or a capsule grouping two actions.

- Fill `glass`, shadow `shadow-glass`, backdrop blur 22px with saturate 190%. Icons 22px in `t1`; a selected action turns `ac-text` (a saved bookmark is filled).
- Use the capsule for related actions on detail screens (북마크 · 공유, 팔로우 · 공유 · 제안하기, 새 대화 · ⋯).
- A count badge sits top-right in `red` with white 11px text.
- Android draws the same buttons flat: no fill, no shadow, icon only.
