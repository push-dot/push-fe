# StatusRow

Shows that the agent is working, Claude Code style.

- A spinning glyph (✢ ✳ ✶ ✻) in `ac`, a rotating verb with a shimmer ("맞춰보는 중…", "끄적이는 중…", "정리하는 중…"), elapsed time in `t3`, and a 중지 button.
- Floats above the Composer as a glass pill. Disappears when the agent finishes or asks something.
- Verbs are casual and specific to the step; never "로딩 중".
