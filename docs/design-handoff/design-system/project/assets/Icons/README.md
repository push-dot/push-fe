# Icons

24px line icons on a 24×24 grid, 2px stroke, round caps and joins. Ink in these files is `t1` light (#16191D); in the product they take the colour of their text (`t1`, `t2`, `t3` or `ac-text`). Sizes used: 16 in chips and badges, 18–20 in rows and buttons, 22–24 in top bars and the tab bar. Filled variants (`home`, `chat`, `user`, `spark`, `bookmark`) mark the selected tab or a saved state.
