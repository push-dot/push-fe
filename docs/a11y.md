# 접근성 체크리스트 (Tauri 웹뷰)

데스크톱 앱이지만 렌더링은 웹뷰 — WCAG 웹 규칙을 그대로 적용한다.

## 커버한 항목

### 키보드 탐색

- [x] 채팅 목록(`ConversationItem`): `div[role=button]` → `tabIndex={0}` 추가, `Enter`/`Space`로 대화 진입. 리네임 input에서 버블링되는 Enter는 `e.target !== e.currentTarget` 가드로 차단.
- [x] 접힌 사이드바 엣지 스트립: `role="button"` + `tabIndex={0}` + `aria-label`. `focus` 시 peek 표시, `Enter`/`Space`로 고정 해제.
- [x] `Escape`: 사이드바 peek 닫기(포커스를 엣지로 복귀), 컨텍스트 메뉴 닫기(기존), `Dialog` 닫기(추가).
- [x] `Dialog`: Mantine `Modal` 기반 — 열릴 때 포커스 트랩으로 이동, 닫힐 때 원래 요소로 복귀.
- [x] 컨텍스트 메뉴(`ContextMenu`): Mantine `Menu` 기반 — 열리면 포커스가 메뉴 안으로 진입, ↑↓/Home/End로 항목 순회.
- [x] 메시지 리스트(`.chat-vlist`): `tabIndex={0}` + `role="log"` + `aria-label` — 키보드로 스크롤 가능.
- [x] 기존 단축키: `⌘B`(사이드바 토글), `⌘⇧O`(새 채팅), `⌘,`(설정) — 마우스 없이 주요 플로우 도달 가능.

### 이름/역할

- [x] 아이콘 버튼: `IconButton`은 `aria-label` 필수 prop으로 이미 강제됨. 컴포저(첨부/설정/중단/전송), 사이드바 토글, 최신 이동 버튼 모두 라벨 있음.
- [x] 활성 네비/대화 항목: `aria-current="page"`.
- [x] 아이콘 SVG는 `aria-hidden="true"`(기존).

### 라이브 리전

- [x] 스트리밍 버블(`.chat-stream-msg-live`): `aria-live="polite"`.
- [x] 스트림 상태줄(`.chat-stream-status`): `role="status"`.
- [x] 토스트: `role="status"`(기존).

### 포커스 표시

- [x] `:focus-visible` 아웃라인 추가: `.sidebar-item`, `.sidebar-edge`, `menuItem`, `.chat-msg-action`, `.chat-vlist`(`components.css.ts`), `button`/`iconButton` recipe(`packages/design-system/src/recipes.css.ts`, `styles.css.ts`).
- [x] `.composer:focus-within` 아웃라인(기존), `input` recipe `:focus` 아웃라인(기존).

## 남은 한계 (후속 과제)

- 가상 스크롤 구간에서 DOM에 없는 메시지는 스크린리더가 읽지 못함.
- 사이드바 리사이저는 마우스 전용(`aria-hidden`) — 키보드 폭 조절 없음.
- 스트리밍 토큰이 `aria-live` 영역에서 매우 자주 갱신됨 — 스크린리더 발화량이 많을 수 있어 `aria-busy` 도입 검토 여지 있음.
